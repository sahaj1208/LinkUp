# LinkUp Frontend

React + Vite client for LinkUp, a full-stack real-time chat and video calling application.

## Development

```bash
npm install
npm run dev
```

Configure `frontend/.env` using `.env.example`.

## Main technologies

- React 19 + Vite
- React Router
- TanStack Query
- Zustand
- Tailwind CSS + DaisyUI
- Stream Chat React SDK
- Stream Video React SDK
